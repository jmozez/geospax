The open-source GIS where maps make themselves.

Drop in data, or plug in a phone, GPS, drone card or sensor logger. GeoSpaX styles it, lays out the map, writes the report and exports PNG, PDF and SVG. When you want control, a full ArcGIS Pro-style workbench is one click away.

Everything a GIS does, without the hours

Two modes, one engine

Lazy: layer cards, a task bar and plain-language next steps. Pro: an ArcGIS Pro-style ribbon, layer tree, attribute table, editing and every pane.

Maps that style themselves

AutoMap picks the field, classes and colours and says why. Full symbology for points, lines, polygons, labels and rasters when you want your own.

Finished maps and reports

Layouts with legend, scale bar, north arrow and inset; Equal Earth for world maps; 150–1200 dpi PNG, vector PDF and SVG; map series.

About 1,130 analysis tools

Vector, raster, terrain, hydrology, imagery and LiDAR in one Toolbox, plus hot spots, kriging and twelve domain plugins.

Data from anywhere

Files, devices and phones, and online data cut to your area with citations: WorldClim, SoilGrids, GBIF, OBIS, GADM, Copernicus DEM, GEBCO, Hansen forest change.

Design and CAD

Roads from a centreline, lots, dimensions, traverses with misclosure, snapping and typed input, and DXF to and from AutoCAD.

Automation

Every result is a re-runnable recipe. Triggers run it when a device is plugged in, a folder changes, a schedule fires or a sensor crosses a threshold.

R, Python and AI

R and Python as recipe steps with an R console; an assistant (Ollama, OpenAI-compatible or Claude) and an MCP server.

Private by default

Everything runs on your computer and works offline. Nothing is uploaded unless you choose to.

Lazy or Pro: the same map, your choice of controls

See it at work

Real data around Lae and the Huon Gulf, Papua New Guinea, over Esri World Imagery.

Twelve domain plugins

One tested toolkit behind every domain, so a tool behaves the same everywhere. Click a map to enlarge it.

Installer for your user only, no admin rights needed. Updates itself from inside the app.

Any Linux (AppImage)

One file for Arch, openSUSE, Mint, Pop!_OS, Ubuntu, Fedora and more: no installing, no admin rights. Updates itself from inside the app.

Download AppImage chmod +x GeoSpaX-*.AppImage && ./GeoSpaX-*.AppImage

Linux · Flathub

Install from Flathub (GNOME Software, KDE Discover) and get updates with the rest of your system.

Get it on Flathub flatpak install flathub io.github.jmozez.GeoSpaX

Web app

Run the web edition on your own server with one command, then open it in any browser.

Run the web edition docker run -p 8080:8080 ghcr.io/jmozez/geospax

Android · GeoSpaX Field

Record points, lines, areas, GPS tracks and photos in the field, with no signal, then send them to GeoSpaX on your computer over Wi-Fi.

Download APK Android 8 or newer · allow "install unknown apps" once
